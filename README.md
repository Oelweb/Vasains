# Vasains

Animierte 3D-Logos aus deinem Logo – gerendert mit Blender.

## Download

Den aktuellen Installer gibt es unter **[Releases](https://github.com/Oelweb/Vasains/releases/latest)**
(`Vasains-Setup-x.y.z.exe`). Die App aktualisiert sich danach automatisch.

## So funktioniert's

1. Logo auswählen (PNG mit transparentem Hintergrund am besten)
2. Farben werden automatisch erkannt
3. Animation rendern – Ergebnis als MP4, GIF und PNG in `Dokumente\Vasains`

Beim ersten Start wird die Render-Engine (Blender 5.3, ca. 425 MB) einmalig eingerichtet.
